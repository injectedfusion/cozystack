## Features and Improvements

* **[talm] feat(config): migrate to Talos v1.12 multi-document config format**: `talm` v0.24.0 can now render Talos v1.12+ machine configuration in the new multi-document format, so operators targeting newer Talos releases no longer need to hand-adjust generated configs or stay on the deprecated monolithic layout ([**@lexfrei**](https://github.com/lexfrei) in cozystack/talm#116).

## Fixes

* **fix(platform): migrate ACME HTTP-01 to ingressClassName API**: ACME HTTP-01 issuance now uses cert-manager's supported `ingressClassName` field and targets the tenant ingress class from `_cluster.expose-ingress` instead of a hardcoded `nginx` class that did not exist on typical Cozystack installs. This keeps certificate issuance working as cert-manager deprecates the legacy annotation path and avoids validation failures from mixing old and new solver fields ([**@myasnikovdaniil**](https://github.com/myasnikovdaniil) in #2436, backport #2439).

## Dependencies

* **[talm] chore(deps): bump dependencies**: Refreshes the `talm` toolchain and core libraries, reducing outdated dependency exposure and keeping the CLI compatible with newer Go and Kubernetes/Talos components ([**@lexfrei**](https://github.com/lexfrei) in cozystack/talm#124).

## Documentation

* **[website] feat(docs): trunk-based versioning with permanent next/ directory**: The docs site now keeps unreleased content under `next/` and promotes it during release publishing, which makes draft documentation easier to maintain without guessing the next version number and keeps version switching consistent across releases ([**@myasnikovdaniil**](https://github.com/myasnikovdaniil) in cozystack/website#495).

* **[website] feat: add Telemetry page under OSS Health section**: Adds a dedicated OSS Health Telemetry page with monthly, quarterly, and yearly usage views, and the follow-up tab-label cleanup makes longer-range periods easier to read. This gives operators and contributors a clearer public view of anonymous Cozystack adoption trends ([**@tym83**](https://github.com/tym83) in cozystack/website#471, cozystack/website#504).

* **[website] feat(blog): taxonomies and client-side filter UI**: The blog now supports topic and article-type filters, and existing posts gained social-preview metadata so release posts and technical articles are easier to discover and share across chat and social platforms ([**@tym83**](https://github.com/tym83) in cozystack/website#499, cozystack/website#498).

* **[website] feat(blog): add managed PostgreSQL with synchronous replication post**: Publishes a step-by-step guide for deploying managed PostgreSQL with synchronous replication on Cozystack, giving operators a concrete reference for highly available database setups ([**@tym83**](https://github.com/tym83) in cozystack/website#497).

* **[website] docs(external-apps): rewrite guide for ApplicationDefinition API**: Updates the external applications guide to the current `ApplicationDefinition` API and chart structure, so integrators can onboard third-party apps using the interfaces that Cozystack actually ships today ([**@kitsunoff**](https://github.com/kitsunoff) in cozystack/website#488).

* **[website] docs(tenants): document namespace layout and parent/child derivation**: Tenant guides now explain namespace derivation, the checkbox-then-edit customization flow, and remove stale links across the v1 docs set. This makes tenant service customization and namespace-aware integrations easier to implement without trial and error ([**@lexfrei**](https://github.com/lexfrei) in cozystack/website#479, cozystack/website#485, cozystack/website#486).

* **[website] fix: update /docs/v1/ redirect to latest v1.2**: Version-agnostic `/docs/v1/` links now land on the current v1.2 docs, and the GitHub Pages build once again downloads the OpenAPI spec before publishing so the hosted REST API reference renders correctly ([**@myasnikovdaniil**](https://github.com/myasnikovdaniil) in cozystack/website#492, cozystack/website#494).
